# Cursor Bugbot review rules

Cursor Bugbot: the review rules for this repository live in
[`REVIEW.md`](../REVIEW.md) at the repository root. Read that file and apply
every rule in it when you review a pull request here.

`REVIEW.md` carries only the judgment rules that the linter and CI leave open;
trust the gates for everything they own (see
[`.agents/project/QUALITY_GATES.md`](../.agents/project/QUALITY_GATES.md)). The
root [`AGENTS.md`](../AGENTS.md) points Codex and Claude at the same file, so
every automated reviewer applies one shared set of rules.
